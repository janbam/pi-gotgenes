  The reply posted this run asks for the split; the verdict itself is unchanged.

- **#929's claim is verified on `main`, and it is a fail-open rather than a missing feature.**

  ```typescript
  if (!trimmedToolName.endsWith(`_${trimmedServerName}`)) {
  if (trimmedToolName.startsWith(`${trimmedServerName}_`)) {
  ```

  (`packages/pi-permission-system/src/access-intent/mcp-targets.ts:70,74`)

  Server derivation requires a suffix match and then explicitly skips prefix-named tools, so `mcp({ tool: "github_search_code" })` produces no `github` candidate and `mcp: {"github": "deny"}` never fires.
